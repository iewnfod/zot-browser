## Plan: 鼠标滚轮翻转 + macOS 系统偏好自动检测

### 修改文件（6个）

#### 1. `src/renderer/src/lib/settings.ts`
- `Settings` 接口新增 `naturalScroll?: boolean`
- `getDefaultSettings()` 默认值设为 `false`

#### 2. `src/main/index.ts`
- 新增 `detectNaturalScroll()` 函数：macOS 下执行 `defaults read -g com.apple.swipescrolldirection`，返回 boolean
- 新增 IPC handler `get-natural-scroll`，返回检测结果
- 在 `app.whenReady()` 中注册（与其他 IPC handler 一起）

#### 3. `src/preload/index.ts` + `index.d.ts`
- `api` 新增 `getNaturalScroll: () => ipcRenderer.invoke('get-natural-scroll')`
- 类型声明同步新增

#### 4. `src/renderer/src/App.tsx`
- `loadSettingsData()` 中：加载 settings 后，若 `naturalScroll === undefined`，调用 `window.api.getNaturalScroll()` 获取系统偏好作为默认值
- 新增 `handleSetNaturalScroll` setter
- 将 `naturalScroll` + setter 传给 `BrowserSideBar` 和 `WebViewContainer`

#### 5. `src/renderer/src/components/WebViewContainer.tsx`
- Props 新增 `naturalScroll?: boolean`
- wheel handler 中：`naturalScroll === true` 时 `deltaX`/`deltaY` 取反

#### 6. `src/renderer/src/components/SideBar.tsx`
- Props 新增 `naturalScroll?: boolean` 和 `onNaturalScrollChange?: (v: boolean) => void`
- 把 `<DropdownItem key="more">More Settings Here</DropdownItem>` 替换为带 checkmark 的自然滚动开关

### 数据流
```
系统偏好 (macOS defaults read)
  → main IPC get-natural-scroll
    → renderer loadSettingsData (仅首次，naturalScroll 未设置时)
      → Settings state
        → WebViewContainer (delta 翻转)
        → SideBar (UI 开关)
        → debounced store.set('settings', ...)
```
